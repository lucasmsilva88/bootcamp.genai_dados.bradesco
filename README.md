# bootcamp.genai_dados.bradesco
Esse repositório refere-se ao bootcamp GenAI & Dados Dados Bradesco da Dio.me

1 - NotebookLM - Segundo cerébro
O tema principal é a certificação internacional de normas contábeis - ACCA
O objetivo foi criar diferentes formas de estudos aplicados a um tema específico, assim é possível estudar em diversos momentos ou formas, como por exemplo, ouvindo um podcast fazendo caminhada.
As diretrizes foram realizadas através de MCP dentro do Claude conectado ao Gemini Notebook.
O direcionamento claro foi realizar um estudo específico para normas internacionais de contabilidade, sem relação alguma com as leis, normas ou traduções brasileiras de contabilidade.
Eu criei um skill de um professor de contabilidade dentro do Claude para analisar todo o conteúdo entregue pelo Gemini Notebook, sendo assim, pedi para ele criar alguns modelos de prova, mas querendo testar e tendo a disponibilidade dentro do Gemini notebook, também solicitei para criar testes.
